- `supabase/migrations/20260920001300_opportunity_sources.sql`: eight RLS tables, immutable history, reviewed searches, triage and conversion RPCs. See database inventory in opportunity-ingestion.md.
- `apps/web/app/source-actions.ts`: authenticated, validated search/review actions.
- `apps/web/app/(workspace)/opportunities/sources/page.tsx`: protected paginated inbox and connection state.
- `apps/web/components/source-inbox.tsx`: searches, reasons, dates, observed history and review forms.
- Tenant loader/types/workspace: source navigation, converted-source labels and actionable Today warnings.
- `.env.example`, README, architecture/security/database docs and offline migration manifest: configuration and release boundaries.
- Connector/database tests and browser harness: synthetic data only; no real API quota or production database.

## Recommendation and limitations

GO for the approved application-only deployment with source features disabled. **NO-GO for production source migration/activation today** because real API behavior and hosted permissions/actions still need validation. Independent-session PostgreSQL locking has now passed in hosted staging. The local environment has no SAM.gov key configured, so no real source request has been attempted. Approval has been received; the remaining activation dependency is private credential configuration and successful validation, not another general approval.

The current inbox shows the latest 10 versions per record; older history needs operator access. Connector administration is CLI-only. Search reasons preserve the original match and are not automatically recomputed over human dispositions. Publication-window discovery plus 10 rotating tracked rechecks is bounded coverage, not an exhaustive amendment monitor. No source text or attachments were added to AI context.
