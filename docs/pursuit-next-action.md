# Pursuit next-action brief

The existing Suggested next actions panel now combines the selected pursuit's recorded submission deadline, human-confirmed blocker count, open/overdue task counts, and decision freshness with one direct action link. For a requirement or task, it shows the saved assignee when available; otherwise it identifies the missing assignment or responsible role. Existing records, permissions and editors remain authoritative.

Priority is explicit: a current no-bid decision directs the user to its memo rather than response work. Otherwise an imminent/past recorded deadline comes first, followed by missing source/deadline details, unreviewed amendments, an unconfirmed/stale decision, current human-confirmed blockers, overdue assigned work, and routine requirements/guidance. No-bid is considered current only when its saved context matches the loaded decision context. Stale blocker findings remain review work, not current confirmed blockers.

The brief uses already authorized workspace reads. Requirements and tasks are filtered to the selected pursuit; unknown pursuit IDs produce a safe navigation link. It introduces no database migration, external requests, AI calls, automatic decisions or submission actions. Counts reflect visible loaded records at page load, not completeness or eligibility. Other members are identified by role and a short member identifier because this workflow does not load a private email directory.

Main files: `lib/workspace-guide.ts` (existing priorities), `lib/pursuit-attention.ts` (scoped summary), `components/workspace-guide.tsx` and `pursuit-attention.module.css` (brief). Tests cover current no-bid, stale decisions, amendment priority, confirmed versus stale findings, overdue tasks, unavailable pursuits and desktop/mobile links.
