# Connected bid review

This release connects the existing live requirements, evidence-use reviews, human requirement dispositions, assigned pursuit tasks and bid/no-bid decisions. It adds an entry point for public notice excerpts, a scoped next-action summary and a downloadable plain-text review brief on authenticated pursuit pages.

Capture managers and organization administrators can paste one identified notice page or section, supply its title/version and location, and review possible requirements. The helper runs entirely in the browser and selects lines containing obligation words. It is deliberately labeled as a text helper, not AI extraction or a complete solicitation analysis. Conditions remain verbatim when they are on the same line. Wrapped paragraphs, tables, cross-references and obligations without matching words require manual review. The UI discloses omitted long lines and the 20-candidate limit. The source excerpt is limited to 24,000 characters and matching lines to 1,200 characters.

Each candidate opens the existing authenticated requirement form. It prefills the source quotation and user-supplied page/section, requires a browser acknowledgement of original-source review, and leaves compliance status at Needs review. The acknowledgement is a usability check, not a server-enforced approval or an attestation record. Saving uses the unchanged server action, role checks, owner validation, tenant RLS, mutation allowance and optimistic concurrency controls. Quoted citations remain editable shared register text, not immutable document provenance or independently authenticated sources. Full pasted excerpts are not sent to an AI service or stored; selected quotations are saved only when a user saves a requirement.

The summary directs readers to unresolved requirements, missing ownership, remaining review gaps, open tasks or the human decision. Counts describe visible review progress, not qualification. Changed decision contexts remain prominently flagged. Exports include visible requirement text, citations, owners, status, approval counts, open tasks and the shared human decision, but do not export profile fact values or private evidence-review reasons. Workspace information still needs appropriate handling by the downloader. Existing data limits and role-filtered visibility are disclosed; this is not an archival evidence snapshot.

No database migration, additional credentials, paid hosting or AI model change is required. Production PDF uploads remain disabled pending the private scanning worker. Automated AI extraction, evidence matching, immutable source snapshots, amendment impact analysis, capacity planning and outcome learning remain future work. This increment should be piloted with actual solicitations before claiming complete notice coverage or time savings.

Validation: nine targeted source-fidelity, bounded-output, prompt-as-data, scoped-export, stale-decision and existing requirement/brief regression tests passed. TypeScript, lint, secret scan and the production build passed. The extended synthetic staging capture test passed the excerpt-to-saved-requirement path, ownership, quoted-condition persistence, export, stale edits, invalid-owner rejection, revoked roles and mobile containment against the hosted staging database using an isolated local app. Synthetic records and account were removed and the fixture was suspended again. No production business records were created for testing.
