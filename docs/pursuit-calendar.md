# Pursuit calendar download

Open a pursuit → **Open bid control** → **Take these dates to your calendar**. Leave **Include open task deadlines** selected for the complete visible task-date set, or clear it for the recorded submission deadline only. Check the available/excluded counts, then choose **Download calendar (.ics)** and import the file into your calendar. Set notifications there.

The download is a one-time snapshot. Amendments, rescheduled dates, task completion and removed tasks do not update or remove imported entries. Review or replace entries after changes; calendar importers may create duplicates on reimport. The download is independent of the timeline's display filter. Invalid/missing dates or time zones are excluded; the existing task-limit warning remains visible. Past dates remain included so overdue work is not silently omitted.

The implementation reuses the already-authorized pursuit snapshot and existing bid-control date validation. No API route, database migration, subscription, integration, invitation or external calendar write is added. Only visible pursuit/task titles, recorded dates and authenticated app links are exported. Evidence, financial records, task notes and member details are omitted. `CLASS:PRIVATE` is an import hint, not an access-control guarantee; the destination calendar controls sharing.

Calendar serialization follows [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545): CRLF, UTF-8 folding at 75 octets, escaped TEXT, stable organization/pursuit/record UIDs and UTC timestamps. Events are point-in-time deadline markers with no invented duration, attendees or alarms. Task entries are labeled as deadlines, not meetings. The UI never records a submission or changes a requirement, decision or task status.

Manual acceptance: use a fictional test pursuit with a known submission time, a job-walk task, a completed task and an undated task. Import into the chosen calendar and confirm local displayed times, title labels, sign-in links and excluded entries. Edit a date in BidXchange and verify the imported entry remains a snapshot; review or replace it deliberately. Native calendar imports and authenticated customer use have not been tested by the automated browser harness.
